关于Typora与Obsidian的几点建议：
1. 工具定位：Typora 适合用于项目管理；Obsidian 更适配个人知识库、第二大脑搭建。
2. Obsidian 使用原则：摒弃各类花哨插件，坚持轻量化使用，不依赖繁杂插件功能。
3. 外部内容入库规范：不将公众号、博客原文大量堆砌至个人知识库，此类内容对个人知识沉淀意义极小，且基本不会二次回看；仅对极重要文章留存网址链接即可，普通内容无需收录。
4. 知识沉淀核心：所有外部内容，需用自身语言重新梳理、重组核心要点，依托持续积累搭建专属、成体系的个人知识体系。
5. 长期核心逻辑：AI 逐步迭代后，普通博客、公众号内容会逐步失去价值，但个人知识库无可替代；AI 无法知晓个人的知识基础、理解认知。深耕所属领域，无需熟记所有细碎知识点、算法、格式细节，但必须清晰每个知识点在自身知识体系中的定位与归属，筑牢系统化、扎实的领域基础。
